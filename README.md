# Зверушки — версия для телефона

Спокойная игра-карточки для малыша. Открывается в Safari на iPhone; «Поделиться» → «На экран „Домой“» — и она работает как приложение.

Картинки нарисованы для игры; звуки, слова и видео — с Wikimedia Commons под свободными лицензиями (авторы: `assets/sounds/CREDITS.md`, `assets/videos/CREDITS.md`).

Семейные фото сюда не входят: их добавляют на самом телефоне (настройки → «Фото семьи»), они хранятся только там.
